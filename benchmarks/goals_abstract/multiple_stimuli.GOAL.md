# Goal: Multiple Simultaneous Stimuli

## Scientific Question
I want to stimulate multiple brain regions with different patterns simultaneously and observe how the responses interact. How do I set this up?

## Expected Output
A Jupyter notebook that:
- Sets up a brain simulation with multiple stimulus targets
- Applies different temporal patterns to different regions
- Shows how evoked activity propagates through the network
- Quantifies the interaction between stimulated regions
- Discusses what the interaction patterns reveal about connectivity
