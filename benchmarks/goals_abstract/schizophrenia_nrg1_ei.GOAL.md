# Goal: Schizophrenia Modeling with Excitation-Inhibition Balance

## Scientific Question
Schizophrenia has been linked to altered excitation-inhibition (E/I) balance. How can I model the effect of NMDA receptor hypofunction on whole-brain dynamics?

## Expected Output
A Jupyter notebook that:
- Builds a brain network model with tunable E/I balance parameters
- Simulates different "genotypes" corresponding to schizophrenia-related mutations (NRG1, ErbB4)
- Compares dynamics across genotypes quantitatively  
- Identifies which network properties are most affected by E/I disruption
- Discusses how the results relate to clinical observations in schizophrenia
