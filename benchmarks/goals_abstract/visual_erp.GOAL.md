# Goal: Visual Evoked Response Potentials

## Scientific Question
When we show someone a visual stimulus, their brain produces an evoked response. How do I model a visual evoked potential (VEP) in a whole-brain simulation?

## Expected Output
A Jupyter notebook that:
- Sets up a brain simulation with visual cortex stimulation
- Models the temporal pattern of a visual stimulus
- Shows the evoked time series in early visual areas
- Compares responses under different stimulation parameters (frequency, amplitude)
- Discusses what the response patterns tell us about visual processing
