# Goal: Comparing Brain Connectivity Normalization Methods

## Scientific Question
Structural brain connectivity matrices can be normalized in different ways. How does the choice of normalization affect simulated brain dynamics?

## Expected Output
A Jupyter notebook that:
- Loads a structural connectivity matrix
- Applies at least two different normalization schemes
- Runs simulations with each normalized connectome
- Compares the resulting dynamics quantitatively
- Discusses which normalization is appropriate for which scenario
